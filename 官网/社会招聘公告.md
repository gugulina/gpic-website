幻想乡电力投资集团（以下简称「本社」）为立足华北电力大学的东方 Project 二创社团，以「由幻想，向未来」为宗旨，主要从事同人绘画创作、周边制品开发与展会参展事务。为充实本社创作与运营队伍，现面向社会公开招募以下岗位人员，有关事项公告如下。

## 一、招募范围

热爱东方 Project 系列作品，认同本社宗旨，并具备稳定投入意愿者。

## 二、招募岗位、职责与要求

本次共设四类岗位，各类岗位的职责、要求与培养安排如下。

### （一）画师 / 画师管培生

1. 岗位职责：承担本社插画、立绘、图稿等原创美术创作，参与社刊及周边制品的美术部分工作。
2. 任职要求：具备一定绘画基础与完稿能力者优先录用；无基础而有意从零开始学习者，同等接受。
3. 培养说明：本社对管培生实行「师带徒」制，由在社画师带教，包教包会；管培期满经考核合格者，转任正式画师。

### （二）美工 / 美工管培生

1. 岗位职责：承担本社活动海报、宣传横幅、刊物排版、周边制品打样稿等平面设计与美术加工工作。
2. 任职要求：与画师岗一致。具备平面设计、排版或制图软件基础者优先；无基础者可从零培养。
3. 培养说明：与画师岗一致，师带徒，包教包会。

### （三）驻场人员

1. 岗位职责：于 THO、THP 等大型东方 Project 展会期间作为本社摊位值守人员出展，承担摊位看管、制品销售、现场接待等事务。
2. 任职要求：展会期间能够到场；性格外向、善于沟通者优先。
3. 相关保障：出展所需摊主证由本社统一提供。

### （四）宣发岗

1. 岗位职责：对接宣发机器人，承担宣传文案的撰写与发布，跟进宣传节奏与效果。
2. 任职要求：文字表达清晰、能按时交稿；熟悉社群传播、有文案撰写经验者优先。

## 三、报名与录用

1. 报名时间：即日起至 2026 年 12 月 27 日。
2. 报名方式：添加本社招新联系人 QQ（2777381538），并提交附件一《报名简历》所要求的全部信息。
3. 录用流程：报名 → 线上简谈 → 见习试岗（一个月）→ 正式录用。
4. 结果反馈：无论录用与否，均于三个工作日内答复。

## 四、其他说明

1. 一人可报多个岗位；报名岗位仅作意向登记，不构成固定分工。
2. 本社各岗位均由爱好者自愿参与相关事务；实际承担的工作不限于报名时所选岗位，由社内需要与个人意愿协商确定。
3. 未列于本次招募范围内、但对本社创作或运营事务有兴趣者，同样欢迎联系。
4. 本社系东方 Project 二创社团，「幻想乡电力投资集团」及其下属企业均为架空设定，与现实企业无关。
