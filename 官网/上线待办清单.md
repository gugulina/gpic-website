## 三、站点基建（✅ 已全部补完）

### 3.1 搜索引擎收录

- [x] `robots.txt` —— 已建（项目根目录）。**只是一份带说明的模板**，打包时会把注释剥掉、
      按域名写上正确的 `Sitemap` 行后放进发布包。已禁止抓取 `/admin.html` 与 `/scripts/`
- [x] `sitemap.xml` —— 已建。**打包时由 `deploy.py` 按 `content.json` 的真实内容重新生成**，
      含首页、公告列表、以及每一条已发布的公告详情页（每条都会带上最后更新日期）
- [ ] ⚠️ **域名定下来之后，必须用 `--site-url` 重新打包**，否则发布包里不会包含 `sitemap.xml`，
      `robots.txt` 里也不会有 `Sitemap` 行（理由见下）

> 为什么不给域名就不生成 sitemap：站点地图必须写绝对地址。放一份填着占位域名的上去，
> 只会让搜索引擎反复抓失败，不如干脆不给。这是刻意设计，不是漏做。

### 3.2 `404.html` ✅

- [x] 已建。访客把地址打错时会看到本站自己的提示页（品牌页头页脚 + 大号 404 +
     显示他实际访问的地址 + 三个出口按钮），而不是托管商那套默认英文错误页
- [x] 本地预览也已同步：本地服务器现在也会用这个页面响应错误地址，本地和线上表现一致
- [ ] ⚠️ 上线后确认托管平台**已开启自定义 404**（多数平台会自动识别根目录的 `404.html`）

> 注意：`404.html` 是整站唯一用「站点根绝对路径」（以 `/` 开头）的页面，因为它可能在
> 任意目录深度下被触发。**放域名根目录或独立子域都没问题；放子目录里托管需要改路径。**

## 四、上线决策（只能你定）

### 4.1 托管放哪 —— **已倾向：走国内备案，但暂缓**

- [x] **路线已定**（2026-09-20）：走中国大陆托管 + ICP 备案，**但暂时搁置**，等真要上线时再买主机。
- [ ] 真要上线时，域名 + 主机一次买 1 年。

#### 备案名已定：「幻电投企划」

原名「幻想乡电力投资集团」拿去备案会被驳回——个人备案的网站名称不能含「集团」这类主体字眼，
「投资」又属金融类词（需前置审批），两个雷都踩。「幻电投企划」都避开了，站内架空设定不受影响。

**这个名字改过两次**（2026-09-20）：先定的是「幻想电力企划」，后来发现「**电力**」也属行业词，
仍有被挑出的概率 —— 不如一次到位，改用社团自称号「幻电投」加「企划」。
**「幻想电力企划」作为备选名保留**：万一「幻电投企划」被驳，换回来只需改 `site.name`
及各页静态兜底，比重报一个新名字省事得多。

> **别被「云服务器」的价格吓住**：能用来备案的最便宜产品是**轻量应用服务器**，
> 新用户活动价约 **38 元/年**（2核2G）；云虚拟主机更便宜。门槛只有两条：
> **中国内地节点 + 包年包月满 3 个月**（买 1 年正好满足）。免费试用款和按量付费的**不算数**。
> 总开销 ≈ 域名（.cn 首年 18–30 / .com 65–72）+ 主机 38–100 元/年。
>
> **现在不买反而是最优解**：域名与主机都按年计费，早买就是纯烧钱；而且**新用户优惠一辈子只有一次**，
> 别浪费在试错上。等确定上线时再买，优先等大促（双11 / 618 / 年初）。

- [ ] **域名必须在境内注册商买**（阿里云 / 腾讯云）。海外注册商的域名回头备案会卡死 —— 这条最容易翻车。
- [ ] 备案期约 7–20 个工作日，**这段时间网站必须关着**（未备案域名不准提前上线访问）。
      所以素材最好在买主机之前就备齐，别让等待期空着。
- [ ] 备案通过后 **30 日内**，去 `beian.mps.gov.cn` 补办**公安联网备案**。

> 合规提示：站点**不收款、不下单**，购买一律跳转闲鱼，这条已经满足「个人备案非经营性」的要求。
> 另一个小提醒：「电力」仍算行业词，有极小概率被管局挑刺；真被要求改，换个词重报即可，**不影响域名**。
