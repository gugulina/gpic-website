# 后台上手与交接说明

> 给「拿到管理员账号、但不在同一台电脑上」的人看。
> 如果你就是这台电脑的主人，看《账户与权限说明.md》就够。

---

## 零、先明白一件事

后台不是一个网站，是**跑在某台电脑上的一个程序**。

- 它默认只监听 `127.0.0.1`，意思是「只有这台电脑自己能用」
- 线上 `gugulina.github.io` 那份是**纯静态快照**，没有后台（`admin.html` 在那里是 404）
- 所以：账号只是钥匙，**门开在哪台机器上，人才进得去**

交接要做的，是把这扇门打开到对方能走到的地方。

---

## 一、先建账号（主催在本机做）

1. 打开 `http://127.0.0.1:4321/admin.html`
2. 侧栏 → **账户管理** → **+ 创建管理员**
3. 填用户名（2–32 位英文、数字、下划线）和初始密码（≥6 位）
4. 建完后在列表里点这个账号的 **编辑**，勾选「可编辑页面」

内容管理员一般勾这几项：

| 页面 | 什么时候勾 |
|---|---|
| 新闻公告 | 要发公告、改通告 |
| 周边商品 | 要改价格、上架、标售罄 |
| 通贩商店 | 要改购买链接、淘口令 |
| 图片管理 | 要自己传图（**不勾就只能用已有图**） |
| 站点设置 | 只有需要改页脚、备案号、社交简介时才给 |

**不要给**的：「数据迁移」（会把整库覆盖）、「账户管理」（只有主催可见，本来也给不了）。

### 密码怎么给

**分渠道发。** 用户名走微信，密码走短信或当面说。
别在同一个聊天窗口把「账号 + 密码」一起发出去——那个窗口一旦被翻到，等于全给了。

第一次登录后让对方立刻在 **我的账户** 页改密码。

## 二、让对方连进来

按「你俩的电脑能不能互相看到」选一种。

### 方案 A：虚拟局域网（推荐，免费）

用 **Tailscale**。它把两台电脑拉进同一个虚拟局域网，流量端到端加密，不用买域名、不用备案。

**你这边：**

1. `tailscale.com` 注册账号（个人免费版够用）
2. 本机装 Tailscale 并登录
3. 后台 → Users → Invite，把邀请链接发给对方
4. 双击 **`启动自持站（远程）.bat`**（不是原来那个）
5. 窗口会打印类似：

```
已对外开放，别人用下面这些地址访问（不是 127.0.0.1）：
  http://100.101.102.103:4321/admin.html   [Tailscale]  虚拟局域网
```

6. 把 **带 `100.` 开头** 的那条发给对方

**对方那边：**

1. 装 Tailscale，用你发的邀请链接登录
2. 浏览器打开你给的 `http://100.x.x.x:4321/admin.html`
3. 登录，改密码，开始用

> 为什么不能给对方 `127.0.0.1`：那个地址在任何电脑上都指「自己」，对方打开只会看到自己的电脑，连不上你。

### 方案 B：Cloudflare Tunnel（要域名）

如果你已经有域名，可以用这个，不用装客户端、对方直接开普通网址。
但要先买域名（约每年几十到一百多），并且要装 `cloudflared`。没域名就别走这条。

### 方案 C：云服务器

把整套搬上去，24 小时在线，不依赖你的电脑开没开。
代价是月付，且要重新配环境、迁数据。等社团规模上来再考虑。

### 网络不通先查这三样

1. **防火墙**：第一次启动会弹窗，要允许「专用网络」。
   没弹过就手动加一条（管理员权限的命令行）：
   ```
   netsh advfirewall firewall add rule name="GPIC 4321" dir=in action=allow protocol=TCP localport=4321
   ```
2. **服务窗口还开着吗**：关掉窗口 = 所有人都连不上
3. **Tailscale 两边的开关都打开了吗**：在托盘图标里看

## 三、对方能做什么，不能做什么

| | 内容管理员 | 主催 |
|---|---|---|
| 改勾选过的页面 | ✅ | ✅ |
| 传图 | 勾了「图片管理」才行 | ✅ |
| 管账号、改别人权限 | ❌ 侧栏没有入口 | ✅ |
| 数据迁移 | ❌ | ✅ |
| 改自己的账户名/密码 | ✅ 我的账户页 | ✅ |
| 点「同步到公网」发布 | ❌ 见下一节 | ✅ |

**侧栏看不到的页面，不是「藏起来」，是真的调不通**：后端每个写接口都按内容域校验，绕过界面直接发请求也是 403。

## 四、改完之后怎么上线（最容易误会的一节）

后台里的「保存」只写进**你电脑上的数据库**。公网那份静态站不会自动变。

要上线，得跑一次 **`同步到公网.bat`**（导出 → 重构静态快照 → git push）。

所以有两种交接深度：

| 形态 | 对方改内容 | 谁点发布 | 适合 |
|---|---|---|---|
| **半放手**（推荐起步） | ✅ 远程改 | 你，有空时点一下 | 对方只管内容，你保留发布权 |
| **全放手** | ✅ | 对方，需要远程操作你电脑 | 你要长期不在 |

**半放手**已经能解决 90% 的问题：对方随时改，你不用等他上门；你每天点一次同步就行。

**全放手**需要额外给两样东西：

1. 把你电脑的**远程桌面**开放给他（Windows 自带「远程桌面」，需要你在系统设置里允许）
2. 把你的 GitHub 账号加进仓库 collaborator（否则 `同步到公网.bat` 推不上去）

> 只给后台账号、不给远程桌面，对方是没法自己发布的——这一点提前说清楚，别等交接完了才发现。

## 五、安全红线

这个站现在是**能被人从外部连进来**的状态，下面几条不是建议，是必须：

1. **初始密码必须换**。超过 6 位、别用社团名、别用 `gpic2026` 这种。
2. **不交接时关掉窗口**。`启动自持站（远程）.bat` 开着，同网络的人都能连。
3. **登录已经有限流**：同一用户名连续错 5 次锁 15 分钟。对方被锁了不是坏了，等一会儿。
4. **主催账号不外借**。主催能删账号、能改别人权限，出问题没人兜底。
5. **定期备份**。`备份.bat` 会存整库 + git 历史，改坏了能回到前一天。

## 六、交接清单

给出去之前，逐条打勾：

- [ ] 账号已建，权限勾选正确（截图发给对方确认）
- [ ] 对方能打开登录页，并成功登录一次
- [ ] 对方已改掉初始密码
- [ ] 对方知道「改了要等人点同步才上线」
- [ ] 对方知道「侧栏看不到的页面 = 没权限」，不是故障
- [ ] 万一被锁 15 分钟，知道是限流不是崩了
- [ ] 你保留了 `备份.bat` 最近一次备份
- [ ] 不交接时，远程启动的窗口会关掉

## 七、排错

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 打不开页面，转圈后超时 | 服务窗口关了 / 防火墙拦了 / 虚拟局域网没连上 | 依次查这三样 |
| `unknown_action` | 服务跑的是旧代码 | 关掉窗口，重新双击启动脚本 |
| 登录提示「失败次数太多」 | 触发限流 | 等 15 分钟；急用就重启服务（计数在内存里，会清零） |
| 登录后侧栏只有两三项 | 权限就勾了这些 | 正常，不是 bug |
| 保存成功但公网没变 | 没点同步 | 跑 `同步到公网.bat` |
| 改了图但线上还是旧图 | 静态快照没重建 | 同上，同步脚本会重建 |
