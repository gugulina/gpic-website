# 版本记录

幻电投企划官网的对外版本号。规则见 [版本号规范.md](版本号规范.md)。

- 版本号格式：`MAJOR.MINOR.PATCH`
- 真源：`web/version.json`（改版本只走 `node scripts/version.mjs bump ...`）
- **不要和 `content.json` 的 `version: 5` 搞混** —— 那是内容结构版本，管的是"前端能不能读懂这份数据"，跟对外版本号是两条线。

## [1.0.0] · 2026-10-19 · 自持站正式版

第一个可以完整交付的版本：内容不再依赖任何第三方平台，改完内容点一个脚本就能上公网。

- **自持动态站**：Node 22 + `node:sqlite`，零 npm 依赖，一条命令起站。替代原 Qoder Sites + Supabase（额度用尽后整站 429）
- **后台可控内容**：站点设置、首页横幅、公告（含 blocks 自由排版）、品牌、商品、通贩、参展、招募、社交链接、图片上传（自动转 WebP）
- **商品三态**：`on_sale` / `sold_out` / `off_shelf`，后台可手动切换；售罄仍展示但沉底，下架前台完全不可见
- **首页商品精选**：有序 id 数组，后台可加入/移除/排序，未入选商品不出现在首页
- **两条发布通道**：自持站直出；`同步到公网.bat` 导出 content.json → 构建静态快照 → 推 GitHub Pages
- **备份体系**：`备份.bat` 一键全量快照 + bundle，含 git 探测兜底
- **版本号机制**：`web/version.json` 单一真源，页脚 / 响应头 / 提交信息 / git tag 全部由脚本派生（本版新增）

内容结构版本：`contentVersion 5`（未变）。
